# DOLMUŞ KAPISI KAPANMADAN SON NEFES

> Sürüm 0.4 — “abi bir kişilik yer var mı” protokolü

Bu depo, Türkiye Cumhuriyeti sınırları içindeki tüm dolmuşlarda, kapı kapanmadan önceki son dört saniyeyi **bilimsel ciddiyetle** simüle eder. Yazılım endüstrisinin çözemediği asıl problemi çözer: içeride yer yoktur, dışarıda bahane vardır, şoförün eli kapıdadır.

Patates yoktur. Çaydanlık da yoktur. Sadece metal kapı, plastik koltuk ve toplumsal sıkışma vardır.

## Neden var?

Çünkü birisi “durduk yere repo aç” dedi. Kapı da durduk yere kapanır. Tesadüf müdür, kader midir, belediye midir: bu depo yorum yapmaz, sadece geri sayar.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Bağımlılık olsaydı o da kapıda kalırdı.

```bash
python3 son_nefes.py
python3 son_nefes.py --yolcu 11 --hiz 0.25
python3 son_nefes.py --protokol resmi
```

Çıkış kodu, kaldırımda kalan yolcu sayısıdır. Sıfır ise mucize gerçekleşmiştir; loglara “herkes bindi” yazılır, kimse inanmaz.

## Resmi özellikler

- Geri sayım (4…3…2…1… kapı)
- Rastgele bahane üretimi (“çocuğum okulda”, “abi bir durak”, “kartım içeride”)
- Şoför ruh hali: merhametli / nötr / kapı filozofu
- Kaldırım istatistiği
- Gizli dosya. Açmayın. Açarsanız sorumluluk size aittir, bize değil. (özellikle `.gizli/`)
